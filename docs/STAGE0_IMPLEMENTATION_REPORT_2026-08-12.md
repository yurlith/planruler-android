# PlanRuler — отчёт о реализации этапа 0

Дата: 12 августа 2026 года  
Версия: `1.0.0-rc3-stage0`, `versionCode 10002`

## Результат

Локальная программная часть этапа 0 реализована. Приложение теперь не только сохраняет
коэффициент масштаба, но и показывает происхождение калибровки, предупреждает о слабом
эталоне, позволяет проверить масштаб независимым контрольным отрезком и включает эти
сведения в проект и PDF-отчёт.

Этап 0 нельзя считать полностью принятым до тестов на двух физических телефонах и
20 реальных документах. Эти проверки требуют устройств и клиентских PDF и не заменяются
эмулятором или синтетическими fixtures.

## Реализовано

### Доверие к масштабу

- постоянный индикатор масштаба использует четыре состояния: подтверждён, вероятно точен,
  требует проверки, отсутствует;
- статус доступен не только цветом: экранный reader получает текстовое описание;
- ответ «печаталось без изменения размера» теперь влияет на статус масштаба;
- контрольный отрезок с ошибкой не более 1% подтверждает масштаб, с большей ошибкой
  переводит его в состояние «требует проверки».

### Мастер калибровки

- известная длина по умолчанию вводится в единицах текущего проекта;
- перед применением показывается вычисленный коэффициент в метрах на точку PDF/пиксель;
- для отрезка короче 10% ширины страницы показывается явное предупреждение;
- для изображения показывается предупреждение о перспективе и растяжении;
- для PDF напоминается проверить, не является ли страница растровым сканом;
- после калибровки предлагается необязательный независимый контрольный отрезок;
- контроль показывает ожидаемую длину, измеренную длину и процент расхождения.

### Происхождение калибровки

В проекте сохраняются:

- дата и время;
- имя исполнителя либо безопасное локальное значение по умолчанию;
- номер страницы;
- метод калибровки;
- длина эталона и единица или печатный масштаб;
- подтверждение неизменного размера печати;
- результат последнего контрольного измерения.

Схема проекта поднята с 2 до 3. Старые проекты схем 1–2 открываются без потери масштаба;
новые поля для них остаются пустыми до следующей калибровки.

### Сохранность данных

- завершённое измерение, калибровка, контроль, редактирование, удаление, undo/redo,
  изменение единиц и слоёв запускают немедленное атомарное сохранение;
- параллельные записи сериализованы mutex, поэтому более старая запись не может завершиться
  после новой и перезаписать её;
- при уничтожении `ViewModel` выполняется последняя синхронная запись;
- репозиторий по-прежнему пишет временный файл, проверяет JSON, сохраняет предыдущую
  корректную версию и затем атомарно заменяет основной файл.

### PDF-отчёт

Если включена информация о масштабе, штамп теперь содержит:

- коэффициент масштаба;
- дату калибровки и исполнителя;
- метод и страницу;
- ожидаемое/измеренное значение контрольного отрезка и расхождение.

### Zoom/pan

Сохранена ранее внесённая архитектура плавного увеличения:

- viewport обновляется внутри жеста локально, без перезапуска pointer stream;
- запись viewport и запрос тайлов выполняются после стабилизации;
- масштаб тайлов квантуется степенями двойки для повторного использования LRU-кэша;
- нечисловые samples жеста отбрасываются.

## Автоматическая проверка

- 36 JVM-тестов калибровки, контрольного отрезка, сериализации, миграции схемы и движка;
- компиляция Android instrumentation tests;
- Android-сценарий: PDF → масштаб → контрольный отрезок → измерение → recreation → экспорт;
- Android-сценарий: повёрнутый JPEG → pinch → ручная калибровка → измерение → recreation;
- полный набор из 20 Android instrumentation tests на эмуляторе API 35: 8 сценариев
  приложения, 8 тестов импорта/рендера и 4 теста экспорта;
- Android lint: 0 issues;
- оптимизированный QA APK подписан схемами v2/v3, установлен и запущен на API 35.

APK и контрольные суммы находятся в каталоге `PlanRuler_APK_2026-08-12/stage0-rc3`.

## Незакрытые критерии выхода

| Критерий | Статус | Что требуется |
|---|---|---|
| 90% пользователей завершают калибровку | Не измерен | Модерируемый тест минимум с 10 участниками |
| Ошибка ≤0.5% vector / ≤1% scan | Частично автоматизирован | Эталонный набор и физические контрольные измерения |
| Нет потери после process death | Автоматическая защита реализована | Финальный destructive process-death прогон на устройствах |
| p95 кадра pinch/pan ≤33 мс | Не измерен на целевом телефоне | Macrobenchmark/Perfetto на среднем физическом Android |
| 20 реальных документов без критических ошибок | Не измерен | Обезличенный набор клиентских PDF/JPEG |

## Решение о готовности

`RC3 stage0` можно передавать на внутреннее и полевое тестирование. Публиковать его как
полностью принятый этап 0 до заполнения протокола физической приёмки нельзя.
