## 2. Базовая точность

На старой редакции создать минимум один линейный замер и один счётчик. Записать
эталонную длину: ________ и итог ведомости до замены: ________.

## 3. Замена листа

1. Открыть «Страницы» → «Заменить текущую страницу» и выбрать новую редакцию.
2. Поставить две пары одинаковых точек как можно дальше друг от друга.
3. Если скан заметно перекошен, добавить третью пару; иначе оставить две.
4. После применения менять прозрачность старого плана от 30 до 70 % и проверить
   совпадение минимум в трёх удалённых областях листа.

| Проверка | Результат |
|---|---|
| Страница заменена, старая не потеряна | ☐ |
| Наложение двигается плавно при zoom/pan | ☐ |
| Совпадение приемлемо в центре и по краям | ☐ |
| Старые замеры не удвоили ведомость | ☐ |
| Перенесённые копии имеют статус «Требует проверки» | ☐ |
